# 飞书多维表格字段

创建“COOC 课程目录”数据表，并使用以下字段：

| 字段 | 类型 | 是否公开 | 说明 |
| --- | --- | --- | --- |
| `课程标题` | 文本 | 是 | 静态卡片标题；必填。 |
| `课程摘要` | 多行文本 | 是 | 面向访客的简短说明。 |
| `分类` | 单选或文本 | 是 | 如“协同课程”“教学成果”。 |
| `公开发布` | 复选框 | 是 | 仅 `true` 的记录进入静态站。 |
| `排序` | 数字 | 是 | 数值越小越靠前。 |
| `封面公开链接` | URL | 是 | 可选 HTTPS 图片 URL；不可填飞书私有附件地址。 |
| `飞书公开文档链接` | URL | 是 | 可选、仅接受 HTTPS `*.feishu.cn` 地址。 |
| `最后更新` | 日期 | 是 | 可选；展示给访客。 |
| `内部备注` | 多行文本 | 否 | 不同步到静态站。 |

长篇教材、版本讨论与协作修订留在飞书文档或知识库。多维表格只管理对外目录、发布状态和公开链接。
