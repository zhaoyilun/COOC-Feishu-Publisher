# 飞书课程维护与 GitHub Pages 发布 HOW-TO

## 1. 进入知识库

登录 `fljx.top` 飞书组织，打开知识库 **COOC 课程内容管理**。飞书是团队编辑后台；学生和公众只访问 GitHub Pages，不需要飞书账号。

## 2. 分配成员权限

进入知识库左下角 **设置 → 成员设置**，按职责添加人员：

- **管理员**：组长和长期维护人员，可管理成员、目录及页面权限。至少保留两名管理员。
- **可编辑的成员**：课程负责人和内容维护人员，可修改课程正文。
- **可阅读的成员**：审核、验收或观察人员，不直接改动内容。

知识库公开范围保持 **仅当前知识库成员可见**。人员离组后应及时从对应角色移除；不得共享个人账号、密码或 GitHub Secrets。

## 3. 编辑与审核课程

1. 在 `公开课程` 中打开对应课程文档并编辑标题、正文、图片或附件。
2. 等待页面显示 **已保存到云端**。
3. 发布前检查版权授权、课程标题、正文、图片和附件是否完整。
4. 草稿、内部资料、未获授权内容和凭证必须放在 `公开课程` 之外。

只有 `公开课程` 下的直接 `docx` 子文档会发布。将课程移出该目录后，下次同步会从公开网站撤下对应页面及媒体。

## 4. 同步到 GitHub Pages

需要立即发布时：

1. 打开 GitHub 仓库 `zhaoyilun/COOC-Feishu-Publisher`。
2. 进入 **Actions → Publish complete COOC courses from Feishu Wiki**。
3. 点击 **Run workflow**，选择 `main` 后再次点击 **Run workflow**。
4. 等待 `sync` 和 `deploy` 均显示绿色 **Success**。

不急时可等待每天北京时间 **10:17** 的自动同步。不要直接修改生成目录 `site/courses/` 或 `site/data/courses.json`，这些内容会在下一次同步时重新生成。

## 5. 发布验收与回滚

发布后访问 <https://zhaoyilun.github.io/COOC-Feishu-Publisher/>，并检查本次修改的课程页：

- 正文、图片和下载附件完整；
- 页面不跳回飞书，也不要求登录；
- 内部资料和未发布草稿未出现。

若内容有误，在飞书中恢复文档版本或将课程移出 `公开课程`，然后重新运行同步工作流。若工作流失败，先查看 Actions 日志，不要手工修改生成页面或提交凭证。
